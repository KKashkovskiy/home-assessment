How saving works

Saving never overwrites: it creates the next version beside the others. Each conversation keeps the version it started on. Activating applies to new conversations only and hot-reloads; if the new version fails to load, the old one stays active. Save refuses a missing placeholder, invalid JSON, a missing tool or a template over its length cap, and warns on characters outside GSM-7. The pack, schema, tools and templates are versioned alongside the prompt.
